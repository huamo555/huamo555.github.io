# ScaleDex GitHub Pages deployment

This repository payload is intended for the public user-site repository:

- Repository: `huamo555/huamo555.github.io`
- Project page: `https://huamo555.github.io/ScaleDex/`
- Keep the research/code repository `huamo555/ScaleDex` private.

## Publish

1. Create `huamo555.github.io` as a **public** repository under the `huamo555` account.
2. Upload the contents of this folder to the root of that repository (keep the `ScaleDex/` directory intact).
3. In **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/(root)`, then Save.
4. Wait for the Pages deployment to complete, then visit `https://huamo555.github.io/ScaleDex/`.

The root `index.html` redirects visitors to `/ScaleDex/`. The paper and supplementary PDFs are intentionally not included.
